# 影影的工作台

一个为创作者设计的移动端个人工作台原型，采用莫兰迪色系、底部导航、PWA（可安装到手机桌面）形式。

## 功能

- **每日任务**：展示今日任务，按分类（每日计划、选题灵感、爆款热点、内容复盘、备忘录、小提琴练习、英语学习）管理。
- **抖音素材库**：手动收集并细分类别：语录金句、文案灵感、视觉参考、音乐/BGM、爆款选题、评论素材。
- **进度环**：首页展示今日任务完成百分比。
- **添加入口**：快速添加任务或素材，自动保存到本地。
- **数据管理**：支持导出/导入 JSON，方便迁移或备份。
- **PWA**：支持"添加到主屏幕"，像原生 App 一样运行。

## 关于抖音自动化

当前版本为**手动录入 + 分类**，原因：

1. 抖音 likes/收藏/评论属于用户隐私数据，需要登录态或抖音开放平台授权。
2. 未经授权的爬取可能违反平台协议。

后续接入自动化方案（任选其一）：

- **抖音开放平台 API**：申请相关权限后，通过服务端定期同步。
- **浏览器插件**：在 PC 端浏览器中登录抖音，插件读取页面数据并写入后端。
- **RPA 工具**：如 Playwright + 定时任务，在个人服务器上运行。

## 手机同步

当前使用浏览器 LocalStorage 存储数据，**只能在本机浏览器内持久化**。真正的跨设备同步需要：

- 部署一个后端（如 Supabase / Firebase / 自建 Node.js）。
- 用户登录账号后，数据上传到云端，多设备同步。

本项目已预留数据结构和导入/导出接口，升级时只需替换存储层。

## 使用方式

1. 在手机上用浏览器打开页面。
2. 点击浏览器菜单 → "添加到主屏幕" / "安装应用"。
3. 即可像 App 一样从桌面启动。

## 本地预览

```bash
cd /workspace/yingying-workbench
python3.11 -m http.server 8080
```

然后在浏览器打开 `http://localhost:8080`。
